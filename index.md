APS Tabby Privacy Policy

Effective date: 11 October 2026
 Last updated: 11 October 2026

1. Introduction

APS Tabby is a browser extension that makes roster navigation easier by replacing the horizontal roster tabs on a supported internal roster webpage with a dropdown list.

APS Tabby is an independent productivity enhancement. The extension does not provide access to the internal webpage and does not change or bypass its authentication or authorization controls.

2. Single purpose

APS Tabby has one purpose:

To display the existing roster tabs on the supported roster webpage as a dropdown while preserving the webpage’s original tab-selection functionality.

APS Tabby does not operate on unrelated websites.

3. Website permission

APS Tabby requires permission to run on the supported roster webpage.

This permission is used only to:

detect the existing roster-tab elements;
read the visible tab labels and date ranges;
determine which tab is currently selected;
create and synchronize the replacement dropdown;
activate the corresponding original tab when the user changes the dropdown selection.

APS Tabby does not use this permission to monitor the user’s general browsing activity.

4. Website content processed

To provide its functionality, APS Tabby temporarily processes limited content from the supported webpage, including:

visible roster-tab labels;
visible tab date ranges;
internal tab identifiers and indexes;
the selected or active tab status.

This information is processed locally in the user’s browser and only while the supported webpage is open.

5. Data collection and transmission

APS Tabby does not transmit website content or user data to the publisher or to any third party.

APS Tabby does not use:

analytics or telemetry;
advertising or tracking technologies;
external APIs or servers;
cloud storage;
remotely hosted code;
third-party data-processing services.

The extension makes no independent network requests.

When a user selects an entry from the dropdown, APS Tabby activates the corresponding original tab element. Any resulting request is handled by the webpage’s existing functionality and the user’s existing authenticated session.

Google considers locally processed website content to be handled user data, even when it is not transmitted. This policy therefore discloses the local processing performed by APS Tabby.

6. Information APS Tabby does not collect

APS Tabby is not designed to collect or process:

names, addresses or contact details;
employee or personnel numbers;
usernames or passwords;
authentication tokens or authentication cookies;
financial or payment information;
health information;
personal communications;
location information;
unrelated browsing history;
form entries or keystrokes;
advertising identifiers.

APS Tabby does not attempt to access or bypass login credentials or authorization controls.

7. Data storage and retention

APS Tabby does not permanently store website content or user activity.

Roster-tab information is held temporarily in the active webpage’s browser memory. It is discarded when the webpage is closed, refreshed or replaced.

APS Tabby does not create user profiles or maintain usage histories.

8. Data sharing and sale

APS Tabby does not sell, rent, transfer, disclose or share user data with third parties.

Website content and user activity are not used for:

advertising;
marketing;
behavioral profiling;
analytics;
creditworthiness or lending decisions;
product monetization;
purposes unrelated to the extension’s visible functionality.
9. Data security

APS Tabby performs its processing locally within the browser.

The extension requests access only to the specific supported webpage required for its single purpose. It does not request access to all websites, browser history, cookies, downloads, local files, clipboard contents or unrelated browser features.

10. Chrome Web Store Limited Use

APS Tabby uses locally processed website content only to provide its stated and visible user-facing functionality.

APS Tabby’s use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. The information is not used for advertising, transferred to data brokers, used for unrelated purposes or provided for human review.

The Chrome Web Store requires privacy information and extension metadata to remain accurate and current.

11. Children’s privacy

APS Tabby is a workplace productivity extension intended for authorized users of the supported internal roster webpage.

APS Tabby is not directed at children and does not knowingly collect personal information from children.

12. Changes to this policy

This privacy policy may be updated if APS Tabby’s functionality or data practices change.

Material changes will be reflected in this policy and in the applicable Chrome Web Store disclosures before the changed version is distributed.

The effective date and last-updated date at the top of this policy identify the current version.
